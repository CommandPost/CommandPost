WebSocket 消息格式

发送命令到 WebSocket 服务器

使用上方选择器选择动作后,发送以下格式的 JSON 消息: 

{
  "type": "command",
  "id": "任意唯一ID",
  "payload": {
    "handler": "Handler ID",
    "actionId": "Action ID"
  }
}

例如,执行 Final Cut Pro 偏好设置: 

{
  "type": "command",
  "id": "msg-001",
  "payload": {
    "handler": "global_cmds",
    "actionId": "preferencesfinalcutpro"
  }
}
